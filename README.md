# 🍏 DEVINTOSH

Here are sources, scripts and other resources to validate an host machine against the requisites of OSX installations.
There are validation scripts, and a fully automated scripting setup for bare metal OSX installation.

## VERSIONS

Currently only Sequoia is implemented.
